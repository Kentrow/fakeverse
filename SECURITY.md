# Security policy

## Supported versions

Security fixes are made on the latest release only, published on PyPI and as a Docker image.

## Reporting a vulnerability

Please do not open a public issue. Report the vulnerability privately with a
[GitHub security advisory](https://github.com/Kentrow/fakeverse/security/advisories/new)
("Security" tab of the repository, then "Report a vulnerability"). Only the maintainers can
read it.

Include what you found, how to reproduce it, and its impact if you know it. You will get an
acknowledgment within 72 hours, and we will keep you informed in the advisory until a fix is
released. Reporters are credited in the advisory unless they prefer otherwise.

Requests from rights holders follow the [takedown procedure](TAKEDOWN.md).
